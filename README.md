# E-commerce-website
A responsive and user-friendly E-Commerce Website built using **HTML, CSS, and JavaScript**. This project provides a simple online shopping interface where users can browse products, search products, add items to the cart, update quantities, and view the total price.

## 🚀 Features

* Product listing with images
* Product search
* Category-based products
* Add to cart
* Remove products from cart
* Increase/decrease quantity
* Automatic total price calculation
* Responsive design
* Interactive user interface
* Mobile-friendly layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Pages
